# 23 条经验：从 271 次真实翻车里熬出来的

> 每条：一句话教训 → 落地规则 → **它在本仓库的机械化载体**（或诚实标注「只能靠流程和人」）。
> 载体图例：🔒 hooks/权限（物理拦截）· 🤖 check-rules（CI 拦截）· 🧪 测试样板 · 📘 Skill（流程注入）· 🏗 架构决策 · 👤 流程+人的关卡

## 第一章 · 开工前

**1. 先让 AI 复述你的需求，再让它动手。**
一句「每个账号一个 workspace」（本意：加个筛选器）被 AI 按字面规划成数据库大手术。AI 执行力越强，理解偏了破坏力越大。
规则：动数据库/架构的任务，AI 先交「理解复述 + 影响面清单」，你确认后才写代码。
载体：📘 `kickoff-restate`

**2. 砍旧功能前，先问它还悄悄干了哪些别的事。**
砍掉试用金（看似只删一行），付款「秒到账」跟着消失——即时到账一直是试用金在垫付。
规则：删任何功能，先交「隐性职责清单 + 每项新归属」，看过才动刀。
载体：📘 `remove-feature`

## 第二章 · 前端

**3. 表单校验要挡在提交之前。**
服务端打回的瞬间，React 19 把表单重置——用户填十分钟的内容被清空，测试全绿。
规则：每个表单配一条测试——故意漏填提交，断言已填内容还在。
载体：🧪 `form-keeps-input.spec.ts`

**4. 文件上传走直传，别塞进普通请求体。**
UI 承诺 20MB，平台请求体 4.5MB 硬顶——用户传 5MB 整页崩溃、后台零日志。
规则：浏览器直传对象存储 + 一条超限额大文件的真实测试。
载体：🏗 直传架构 + 🧪 `upload-large-file.spec.ts`

**5. 验收 UI 只认运行中的截图，不收「做完了」三个字。**
设计稿全确认过，实现出来完全不同（三页返工）；后来又有「搬得一模一样但按钮全是死的」。
规则：你看过运行中截图 + 每个按钮点过 + 每个数字问过来源，三样齐才算完成。
载体：👤 流程门禁（无法机械化，这关就是你）

## 第三章 · 后端

**6. 每一次数据库写入，都必须检查有没有成功。**
271 条里的复发之王：写了 8 遍教训、犯了 8 次。扣费白送、付款不到账，全程无日志。
规则：「写库不看 error」提交直接报错——靠记性为零，靠机器为准。
载体：🤖 `db-write-unchecked`

**7. 跟钱有关的数字，一个都不能信客户端。**
下单接口收客户端传的 cost（可零元购）；扣费无负数守卫（可给自己充钱）；修好后移植旧版又复活。
规则：三连问——价格哪来的？负数会怎样？重放两次会怎样？
载体：🤖 `money-from-client` + 👤 审查三连问

**8. 发出去就收不回的动作，失败了绝不自动重试。**
发布卡死若自动重发 = 账号连发两条同帖，直逼封号。「失败」不等于「没发生」。
规则：执行前查真实终态；失败停下等人工；附带操作出错不得连带重试主动作。立规 90 天零复发。
载体：👤 红线 + 审查（AGENTS.md 红线 1）

**9. 改任何一处逻辑前，先搜一遍谁还在干同样的事。**
同一逻辑两个运行时各一份只改了一份；表三条写入路径只想到两条；同文件另一分支同坑一月后爆。
规则：按名字搜全仓（含定时任务目录），「谁在用它」清单齐了才动手。
载体：📘 `schema-review` 附加检查 + 👤

## 第四章 · 安全与数据库

**10. 权限宁可从零开始给，永远别依赖平台默认值。**
RLS 写策略漏限定 = 任何人可自封任意工作区管理员；函数重建后平台把权限自动授回。
规则：函数建完立即收回公开权限；每次迁移后跑平台安全扫描。
载体：👤 迁移固定动作（可加进 CI）

**11. 评审 AI 设计的表，把四个问题问出口。**
一字段两含义、外键指错表、枚举漏值死循环、原始值丢弃只能重爬。
规则：①字段单一含义？②外键指向查过？③原始值留不留？④枚举是全集？
载体：📘 `schema-review`

**12. 性能问题先把账算清，别让 AI 停在第一个说得通的原因。**
36 个外键零索引（AI 以为自带）；页面慢修三轮才见底——每轮停在第一个说得通的原因。
规则：建表带索引；修性能前先交「时间账单」（每步毫秒数加总对得上总耗时）；对比同时段。
载体：📘（并入 schema-review 附加检查）+ 👤

## 第五章 · 数据与第三方

**13. 接按量计费的 API，第一件事查它的默认参数。**
数量参数默认 50000 条 = 一次调用烧一个月预算；重试重扣 + 空转 cron 烧爆一夜配额。
规则：数量封顶值写死在代码里 + 测试锁住；只有「未计费」错误才重试；「花了钱没拿到数据」要告警。
载体：🏗 封顶值 + 🤖 `dangerous-script` + 👤 成本告警

**14. 「请求成功但结果为空」当事故排查，别当没数据。**
爬虫被拦时返回 200 + 空数组，五层日志全「正常」，产品静默空转数天。「所有告警挂在 catch 上等于没有告警」。
规则：空结果留痕（为什么空）+ 连续空告警；上线前做一次拔线演习。
载体：🏗 留痕设计 + 👤 拔线演习

**15. AI 调 AI 最容易翻车：返回按 ID 对齐，假设它会漏。**
按下标对齐正常时永远是绿的；「不要重复」清单被一字不差抄进答案。写进规范后仍犯 3 次。
规则：业务 ID 对齐 + 漏答重取 + 乱序/漏答/多答测试三件套。
载体：🧪 `llm-batch-malformed.test.ts` + 🤖 `llm-index-align`

**16. 用 AI 做审核闸门，必须设计「判不了怎么办」。**
判定服务一挂，全部归「不通过」→ 全站发布卡死；反向：下游数量兜底把闸门剔掉的偷偷补回。
规则：两问——判不了走哪条路？闸门剔除后最终数量真的变少了吗？
载体：📘（设计评审两问）+ 🧪

## 第六章 · 评测

**17. 测试数据是手工补的，就等于测试替代码干了活。**
用户付 3 票的钱只投出 1 票——验证用手工插的数据，恰好绕开缺失的拆单逻辑。「手工补的每个字段都是被测代码可能漏掉的一步。」
规则：验收只认产品入口产生的数据；手工造数必须列出补了哪些字段、逐个反查。
载体：👤 验收纪律

**18. 测试全绿只说明没退化，新功能上线前真人走一遍。**
硬数据：50 个最严重 bug 里 22 个（44%）是真人验收抓到的；扩展真机一小时挖出 4 个测试结构上测不到的问题。
规则：自动化全绿 + 真人全流程走查，两道关缺一不可。
载体：👤 流程门禁

**19. 知道你的检查工具看不见什么。**
一下午连环 5 个严重 bug 全是「检查全绿」放行——列名是字符串，tsc 不管；单测碰不到真库真页面。「我用看不见这类缺陷的工具证明了缺陷不存在。」
规则：「验证通过」必须标注层级——结构性（类型/单测）还是行为性（真数据/真页面）。
载体：👤 + AGENTS.md 红线 5

## 第七章 · 部署上线

**20. 本地永远撞不出生产的墙，上线前在真实平台跑一轮。**
拆好的两段函数被三轮加重悄悄推回 60 秒墙外——每轮验收都在本地（没有墙），上线被强杀 + 自锁死。
规则：重活上线前真实平台完整跑一遍 + AI 自证最坏耗时，接近上限就拆。
载体：👤 上线前置清单

**21. 环境是第二个代码库——env、版本、进程、产物都会骗你。**
四大骗局各浪费半天以上：shell 变量覆盖、依赖静默装两份、没重新构建、端口旧进程。
规则：先环境四查，再怀疑业务代码。
载体：📘 `debug-env-first`

## 第八章 · 与 AI 共事

**22. AI 会把你的一次授权，当成永久授权。**
说了「先本地验一下」，PR 已合进生产——它把此前「验完就合」的节奏当成常设流程。
规则：合并/部署/发布逐次授权；无分支保护仓库禁自动合并。
载体：🔒 `settings.json` permissions.ask/deny + `guard.sh`（本仓库最硬的一层）

**23. 会话太长 AI 会失忆，开工前让它重读设计文档。**
上下文被压缩后凭印象开工：重做已验证的事、违反自己三天前写的文档。「说不出文档在哪、定了哪几条，就没资格开始写代码。」
规则：长会话派活先三问——文档在哪？定了哪几条？和现在冲突吗？重要决策落仓库文档，对话会压缩、文件不会。
载体：📘 `kickoff-restate` + 👤
